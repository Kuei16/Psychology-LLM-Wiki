# 步驟一｜Wiki Query 本地驗證

本次實際執行的是**檔案式查詢路徑驗證**：從提問對應到 index 的概念頁，再檢查答案摘要的來源筆記是否存在。不是連線式 RAG 的檢索成績。

## Q：心理學是什麼？
- 檢索頁面：`wiki/concepts/psychology.md`
- 檢查結果：**PASS**（檔案存在、可見來源及核心字詞）
- Wiki 回答依據：心理學以科學方法研究心智和行為。觀察、提出假設、實驗與可重複檢驗是此學科的核心方法。

## Q：古典制約與操作制約差別？
- 檢索頁面：`wiki/concepts/conditioning-comparison.md`
- 檢查結果：**PASS**（檔案存在、可見來源及核心字詞）
- Wiki 回答依據：古典制約重點是刺激間的聯結與誘發反應；操作制約重點是行為後果如何影響未來行為。

## Q：記憶有哪些基本功能？
- 檢索頁面：`wiki/concepts/memory.md`
