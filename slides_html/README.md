# 步驟二｜心理學入門教學 HTML 簡報

直接用瀏覽器開啟 `index.html`，無需伺服器或套件。透過下方「上一頁／下一頁」或鍵盤方向鍵切換。全部 13 頁，使用 Wiki 的七篇教材小節筆記作為知識來源。

- 每頁最下方提供該頁所用的 `S01–S07 Wiki` 與原始 OpenStax 小節連結。
- 完整來源關係：`../reports/slide-source-map.md`。
- 教學內容為繁體中文改寫與整理，非 OpenStax 教材原文。
- 若要使用 GitHub Pages 直接呈現，可將 `slides_html/index.html` 複製到網站根目錄，或將 Pages 發布來源設在符合 GitHub Pages 規則的位置。
- 單獨下載 HTML 仍能瀏覽，但外部的 GitHub Wiki 與 OpenStax 連結需要網路。
